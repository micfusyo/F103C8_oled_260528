# 喝水提醒裝置 - STM32F103C8T6

## 專案簡介

這是一個基於KEYSKING的STM32F103C8T6開發板的提醒裝置，主功能是用旋轉編碼器設定倒數時間，透過 OLED 顯示目前狀態，並在時間到時播放蜂鳴器音樂與 WS2812 效果提醒使用者喝水。專案同時整合了 RTC，除了顯示當前日期時間，也能直接在裝置上調整年、月、日、時、分、秒。
驅動程式大部分採用KEYSKING所提供的程序，以及由VSCode的Copilot協助完成的。
KEYSKING的網站連結： https://docs.baud-dance.com/docs/stm32/intro/

## 專案功能

- OLED 狀態顯示：待機、倒數、提醒、RTC 設定畫面
- 倒數提醒：可設定 10 到 60 分鐘的喝水間隔
- RTC 顯示：顯示目前日期時間與星期
- RTC 調整：可直接在裝置上修改年月日時分秒
- 蜂鳴器提醒：倒數結束後播放提示音樂
- WS2812 彩虹效果：提醒狀態時同步輸出燈效
- RGB LED 指示：倒數中會輪流點亮板上的 RGB LED

## 硬體配置

| 功能 | 引腳配置 | 說明 |
|------|----------|------|
| OLED 顯示 | I2C1 PB6 / PB7 | 顯示狀態、時間與操作提示 |
| 蜂鳴器 | TIM4_CH4 PB9 | PWM 輸出，用於播放提醒音樂 |
| 旋轉編碼器 | TIM1 PA8 / PA9 | 用來調整倒數時間與 RTC 數值 |
| KEY | PB15 | 旋轉編碼器的操作鍵，開始/停止倒數、RTC 設定步進 |
| KEY1 | PB12 | 系統重置鍵（軟體重置） |
| KEY2 | PB13 | 從待機進入 RTC 年月日時分秒設定 |

## 系統流程

### 1. 待機狀態

開機後進入 `STATE_IDLE`，OLED 顯示版本、目前倒數分鐘數，以及 RTC 日期時間。

### 2. 設定倒數時間

在待機狀態下旋轉編碼器可調整喝水提醒間隔，範圍為 10 到 60 分鐘，步進 1 分鐘。

### 3. 啟動倒數

在待機狀態按下 `KEY`，系統進入倒數狀態並開始計時。倒數過程中 OLED 顯示剩餘時間，RGB LED 會輪流切換。

### 4. 倒數結束提醒

倒數到 0 後進入提醒狀態，蜂鳴器開始播放提示音樂，WS2812 同步顯示彩虹效果。

### 5. RTC 調整模式

在待機狀態按下 `KEY2`，進入 RTC 設定模式。這個模式用來調整系統時間：

- 旋轉編碼器：增加或減少目前選中的欄位數值
- 按下 `KEY`：進入下一步
- 依序調整：年、月、日、時、分、秒
- 最後一步：使用編碼器切換 `CANCE` / `SAVE`
- 再按一次 `KEY`：放棄或儲存修改並返回待機

## RTC 設定畫面說明

RTC 調整畫面會分成四列顯示：

1. 第一列：`YYYY/MM/DD`
2. 第二列：`HH:MM:SS`
3. 第三列：星期
4. 第四列：目前步驟提示，最後會顯示 `CANCE` / `SAVE`

## 操作說明

### 一般使用

1. 上電後進入待機畫面。
2. 旋轉編碼器調整倒數分鐘數，預設為15分鐘。
3. 按下 `KEY` 開始倒數。
4. 倒數過程中再按一次 `KEY` 可返回待機。
5. 倒數結束後會進入提醒狀態，按 `KEY` 返回待機。

### RTC 時間調整

1. 在待機狀態按下 `KEY2` 進入 RTC 調整。
2. 用編碼器調整年。
3. 按 `KEY` 切換到月，再調整月。
4. 重複操作直到調整完日、時、分、秒。
5. 到最後確認步驟後，使用編碼器選擇 `CANCE` 或 `SAVE`。
6. 再按 `KEY` 完成並返回待機。

### 重置

- 按下 `KEY1` 可直接重置系統。

## 開發環境與編譯

建議使用 CMake 與 Ninja 建置：

```bash
mkdir -p build/Debug
cd build/Debug
cmake -DCMAKE_BUILD_TYPE=Debug ..
cmake --build .
```

生成的目標為 `F103C8_oled_260528.elf`。

## 主要模組

- `Core/Src/ctrl.c`：系統狀態機、按鍵流程、OLED 顯示與 RTC 設定流程
- `Core/Src/kk_rtc.c`：RTC 時間讀寫封裝
- `Core/Src/music.c`：蜂鳴器音樂播放控制
- `Core/Src/ws2812.c`：WS2812 燈效控制
- `Core/Src/rs232.c`：序列埠通訊

## 故障排除

| 問題 | 可能原因 | 建議檢查 |
|------|----------|----------|
| OLED 無顯示 | I2C 接線或初始化異常 | 檢查 PB6 / PB7 與上拉電阻 |
| 編碼器無反應 | TIM1 設定錯誤 | 檢查 PA8 / PA9 與編碼器模式 |
| 蜂鳴器無聲 | PWM 未啟動 | 檢查 TIM4_CH4 與音樂模組 |
| RTC 顯示不正確 | RTC 未初始化或時間未設定 | 先進入 KEY2 的 RTC 調整模式 |
| 按鍵無效 | GPIO 配置異常 | 檢查 PB12 / PB13 / PB15 的輸入配置 |
