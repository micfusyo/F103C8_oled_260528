# 喝水提醒裝置 - STM32F103C8T6

## 📱 項目簡介

這是一個基於 STM32F103C8T6 微控制器的智能喝水提醒裝置。通過設置定時器提醒用戶定時喝水，具有友好的 OLED 顯示界面和便捷的交互方式。

## ✨ 主要功能

### 1. **OLED 顯示屏**
   - 實時顯示工作狀態
   - 顯示倒計時時間
   - 顯示當前設置的提醒時間間隔

### 2. **PWM 無源蜂鳴器**
   - 定時提醒警告聲
   - 可自定義蜂鳴頻率和時長

### 3. **手轉編碼器**
   - 調整提醒時間間隔（範圍：10～60 分鐘）
   - 旋轉編碼器調整，步進為 1 分鐘

### 4. **復位按鈕**
   - 快速重置計時器
   - 返回待機狀態

## 🔧 硬件配置

| 功能 | 引腳配置 | 說明 |
|------|---------|------|
| **OLED 顯示** | I2C1-PB6/PB7 | I2C 通信接口 |
| **蜂鳴器** | TIM4_CH4-PB9 | PWM 輸出，頻率可配置 |
| **編碼器** | TIM1-PA8/PA9 | 定時器捕獲模式 |
| **復位按鈕** | PB15 (KEY) | GPIO 輸入 |

## 📖 操作說明

### 啟動流程

1. **上電初始化**
   - 系統自檢
   - OLED 顯示歡迎畫面
   - 設置默認提醒時間（建議 15 分鐘）

### 日常使用

2. **調整提醒時間**
   - 旋轉編碼器：順時針增加時間，逆時針減少時間
   - 時間範圍：10 ～ 60 分鐘
   - OLED 實時顯示當前設置值

3. **啟動計時**
   - 設置完成後，系統自動開始倒計時
   - OLED 顯示剩餘時間（MM:SS 格式）

4. **定時提醒**
   - 倒計時到 0 時，蜂鳴器發出警告聲
   - OLED 顯示「請喝水」提示
   - 蜂鳴聲持續 2 秒或直至按下復位按鈕

5. **重置計時**
   - 按下復位按鈕：返回空閒狀態
   - 可重新調整提醒時間或直接開始新計時

## 🎯 LED/顯示狀態指示

| 狀態 | OLED 顯示 | 備註 |
|------|---------|------|
| 待機中 | 設置提示 + 當前時間 | 等待編碼器調整 |
| 倒計時中 | 剩餘時間 + 進度條 | 正在計時 |
| 提醒中 | 「請喝水」閃爍 | 蜂鳴器鳴響 |
| 錯誤 | 故障代碼 | 系統異常 |

## 🔌 快速開始

1. **編譯工程**
   ```bash
   mkdir -p build/Debug
   cd build/Debug
   cmake -DCMAKE_BUILD_TYPE=Debug ..
   cmake --build .
   ```

2. **燒錄程序**
   - 使用 STLink 或其他燒錄工具
   - 將生成的 .elf 或 .hex 文件燒錄到 STM32F103C8T6

3. **運行測試**
   - 檢查 OLED 是否正常顯示
   - 測試編碼器和按鈕功能
   - 驗證蜂鳴器聲音

## ⚙️ 配置說明

### 時間設置範圍
- **最小值**：10 分鐘
- **最大值**：60 分鐘
- **步進值**：1 分鐘

### 蜂鳴器參數
- **頻率**：可配置（建議 1000Hz ～ 2000Hz）
- **時長**：可配置（建議 2 秒）

### OLED 刷新率
- **默認**：100ms（推薦值）

## 🐛 故障排除

| 問題 | 原因 | 解決方案 |
|------|------|---------|
| OLED 無顯示 | I2C 通信異常 | 檢查 PB6/PB7 連接和上拉電阻 |
| 蜂鳴器無聲 | PWM 配置錯誤 | 驗證 TIM4_CH4-PB9 配置 |
| 編碼器無反應 | TIM1 未正確初始化 | 檢查 PA8/PA9 引腳配置 |
| 按鈕無效 | 中斷配置問題 | 確認 PB15 中斷已啟用 |
